# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Browser-native modules and Canvas, served by the existing HEIMDALL HTTP server. No frontend build or runtime dependencies.

## Users

Researchers and reviewers exploring SPHEREx data, testing interpretations, and checking the provenance of HEIMDALL findings.

## Capabilities and Constraints

Explore an interactive 2D ICRS sky coordinate map and move between the high-level result and the observations, measurements, hypotheses, and frozen versions behind it. The all-sky view is a navigation surface. Inventory completeness and validated findings require separate evidence. Preserve saved results during outages and surface service-owned job progress. Use the backend as the authority on all scientific claims.
