## Test record

- Command: `python3 -m unittest discover -s tests -t .`
- Environment: Python 3.14.8 on macOS, standard library only, run from the
  project root with `HEIMDALL_*` variables unset.
- Result: `Ran 119 tests ... OK`. The same result with `python3 -W error`
  (warnings as errors).
- Per module: boundaries 11, candidates 14, config 12, data_access 19,
  pipeline 7, registry 19, validity 14, values 23.
- Negative controls run alongside: without the redaction filter, a test secret
  does appear in log output; the import-boundary scanner does detect a
  forbidden import in a constructed file.

## What these tests do not show

- Nothing has been connected to, retrieved from, or validated against a real
  data source.
- The synthetic fixture tests only the software boundary. It contains no
  astronomical data.
- No scientific method, threshold or validation procedure exists yet.
